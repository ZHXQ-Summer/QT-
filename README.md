# 来财二手交易平台 - README

## 项目简介

来财二手交易平台是一个基于Qt6.8开发的跨平台二手商品交易应用，旨在为用户提供便捷的二手商品交易体验。平台支持商品发布、浏览、收藏、评价、私信沟通、个人账户管理等核心功能，采用现代化UI设计和高效的后端逻辑，确保用户获得流畅的使用体验。

## 功能特点

### 核心交易功能
- **商品浏览与搜索**：支持分类浏览、关键词搜索和筛选功能，快速找到心仪商品
- **商品发布**：便捷的商品发布流程，支持多图上传、详细描述和价格设置
- **收藏功能**：可收藏感兴趣的商品，方便后续查看
- **评价系统**：交易完成后可对买卖双方进行评价，建立信用体系

### 社交与账户管理
- **个人账户**：个人信息管理、交易记录查询、发布商品管理
- **私信沟通**：买家与卖家直接沟通，支持文字消息和图片发送
- **编辑功能**：可随时编辑已发布的商品信息、个人资料

### 其他辅助功能
- **收藏夹管理**：整理和管理收藏的商品
- **通知中心**：接收订单、消息和系统通知
- **安全认证**：账户登录、注册与安全设置

## 技术栈

### 前端框架
- **Qt6.8**：核心框架，支持跨平台开发
- **Qt Quick (QML)**：声明式UI开发，实现流畅动画和交互
- **Qt Widgets**：部分组件使用原生控件实现
- **Qt Multimedia**：图片处理与上传功能

### 开发工具
- Qt Creator 10.0+
- CMake 3.16+
- Git 版本控制
